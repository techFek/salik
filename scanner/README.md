# Salik Scan

برنامج على الكمبيوتر بتديله لينك يوتيوب (أو ملف فيديو)، فيعدّ فيه:

- المشاهد الجنسية
- العنف
- المشاهد المقززة والدموية
- التعاطي (تدخين، خمر، مخدرات)
- الألفاظ الخارجة، ومعاها الكلام الجنسي والكلام عن التعاطي

وجنب كل لحظة بيحط صورها وتوقيتها، علشان تتأكد منها بنفسك. كل ما تراجع أكتر، البرنامج بيتعلم من مراجعتك ويبقى أدق.

## التسطيب (مرة واحدة، على ويندوز)

1. نزّل الريبو، وافتح فولدر `scanner`.
2. دوس دبل كليك على **`install-windows.bat`**. هو بيسطّب Python وFFmpeg وDeno (يوتيوب محتاجه) والمكتبات.
   - لو اتسطّب Python أو FFmpeg لأول مرة، اقفل النافذة وشغّل الملف تاني.
3. أول تحليل هينزّل نماذج الذكاء الاصطناعي، حوالي 1.5 جيجا، مرة واحدة بس.

## الاستخدام

**التحليل:** دوس دبل كليك على **`scan.bat`** والصق اللينك. أو من الـ Terminal:

```
python salik_scan.py scan "https://www.youtube.com/watch?v=..."
python salik_scan.py scan "D:\Movies\film.mkv"
```

**صفحة المراجعة:** بعد ما التحليل يخلص، بتفتح لوحدها على `http://localhost:8777`.

- **فوق:** العدد الكلي لكل نوع، وقصاده اللي أكدته واللي رفضته.
- **كل لحظة متعلّم عليها:** ليها صورة، وشريط صور من المشهد، وتوقيت، وزرار **▶** يشغّل المقطع نفسه.
- **تحكم في كل لحظة:**
  - **✓ صح** أو **✗ غلط**.
  - لو النوع غلط، غيّره من القائمة.
  - ممكن تكتب وصف للمشهد.
- **اختصارات الكيبورد:** `Y` = صح، `N` = غلط، الأسهم للتنقل، `Space` = تشغيل.
- **الحفظ:** كل دوسة بتتحفظ لوحدها.
- **تصدير فلاتر سالك:** بيطلّع المشاهد اللي أكدتها كفلاتر جاهزة للمكتبة: الألفاظ بتتكتم، والجنسي والعنف بيتخطّوا، والدموي والتعاطي بيتغبّشوا.

**مراجعة تحليل قديم:**

```
python salik_scan.py review                 (آخر تحليل)
python salik_scan.py review scans\<الفولدر>
python salik_scan.py list
```

### إعدادات مفيدة

| الإعداد | المعنى |
|---|---|
| `--every 2` | صورة كل ثانيتين بدل كل ثانية (أسرع، وده كويس للأفلام الطويلة) |
| `--threshold 0.25` | يمسك أكتر (وهتظهر إنذارات غلط أكتر). الافتراضي 0.35 |
| `--whisper medium` | لو هيستخدم Whisper، سماعه يبقى أدق بس أبطأ. الافتراضي `small` |
| `--whisper-anyway` | يسمع الصوت بـ Whisper حتى لو الفيديو عليه ترجمة يوتيوب |
| `--cookies-from-browser chrome` | لو يوتيوب طلب تسجيل دخول ("Sign in to confirm you're not a bot") |
| `--lang ar` | لغة الصوت لو الاكتشاف التلقائي غلط |
| `--no-speech` | الصورة بس، من غير الصوت |
| `--word "كلمة"` | كلمة زيادة تتحسب لفظ خارج (تتكرر) |

## إزاي الذكاء الاصطناعي بيستفيد من مراجعتك

البرنامج بيحتفظ لكل صورة بـ "بصمة" من نموذج CLIP. ومراجعتك هي اللي بتعلّمه:

1. **قبل أي تدريب:** البرنامج بيعتمد على نماذج جاهزة.
   - للصورة: CLIP بأوصاف زي "شخص بيدخن"، ونموذج مخصوص للمشاهد الجنسية.
   - للألفاظ: الترجمة التلقائية بتاعة يوتيوب، اللي فيها توقيت كل كلمة، مع قوائم ألفاظ سالك نفسها. Whisper بيتستخدم بس للملفات اللي على جهازك أو الفيديوهات اللي مفيهاش ترجمة، ولازم تسطّبه الأول: `pip install faster-whisper`.
2. **لما تراجع:** كل **✓** بيبقى مثال صح للنوع ده، وكل **✗** مثال غلط، وده أهم حاجة بيتعلم منها لأن دي اللحظات اللي اتلخبط فيها. البرنامج كمان بياخد صور من الأجزاء اللي ما اتعلّمش عليها كأمثلة عادية.
3. **التدريب:** شغّل **`train.bat`** (أو `python salik_scan.py train`).
   - بيدرّب نموذج صغير لكل نوع على أمثلتك في ثواني، ومن غير كارت شاشة.
   - بيطبع الدقة التقريبية.
   - بيحفظ النتيجة في `model/heads.joblib`.
4. **من التحليل اللي بعده:** البرنامج بيستخدم النموذج ده لوحده، ورأيك بياخد 70% من الحكم.
5. **عدد الأمثلة:** محتاج 8 ✓ و8 ✗ على الأقل في النوع علشان يتدرب. وكل ما تزيد (مثلًا 100 أو أكتر لكل نوع) الدقة بتعلى.

وكمان `train` بيجمع الصور اللي راجعتها في فولدر `dataset\<النوع>\yes|no\`، ومعاها `labels.csv`. ده dataset جاهز لو حبينا بعدين ندرّب نموذج أكبر (fine-tuning) أو نستخدمه في الإضافة والتطبيق.

## حدود لازم تعرفها

- **العنف والمقزز:**
  - النماذج الجاهزة بتغلط فيهم أكتر من الباقي.
  - الإنذارات الغلط متوقعة في الأول، وده الطبيعي.
  - المراجعة والتدريب هما اللي بيصلحوا ده.
- **الألفاظ:** بتعتمد على ترجمة يوتيوب التلقائية. لو الترجمة كتبت الكلمة غلط أو حطت مكانها `[ __ ]`، الكلمة مش هتتحسب.
- **السرعة:** على كمبيوتر من غير كارت شاشة، فيديو مدته 20 دقيقة بياخد تقريبًا من 5 لـ 10 دقايق، وفيلم ساعتين ممكن ياخد ساعة. ولو عندك كارت NVIDIA ومتسطّب له PyTorch بـ CUDA، هيبقى أسرع كتير.
- **الخصوصية:** كل حاجة بتتعمل على جهازك، ومفيش صور ولا صوت بيتبعتوا لأي مكان. الإنترنت بيتستخدم بس لتنزيل الفيديو والنماذج.

## الملفات

```
scanner/
  salik_scan.py           الأوامر: scan / review / train / list
  salikscan/              الكود (التنزيل، الصور، الصوت، صفحة المراجعة، التدريب)
  scans/                  نتايج كل تحليل (الفيديو، الصور، المراجعات labels.json)
  model/heads.joblib      النموذج المدرَّب على مراجعاتك
  dataset/                الصور المراجَعة لكل نوع
```

النماذج اللي بيستخدمها: [openai/clip-vit-base-patch32](https://huggingface.co/openai/clip-vit-base-patch32)، و[Falconsai/nsfw_image_detection](https://huggingface.co/Falconsai/nsfw_image_detection)، و[Whisper عن طريق faster-whisper](https://github.com/SYSTRAN/faster-whisper). أما قوائم الألفاظ فهي `subtitle-censor-core.js` من جذر الريبو، نفس القوائم اللي في الإضافة والتطبيق.
